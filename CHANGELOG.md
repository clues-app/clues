# Clues - Version Log

Short notes on what's new. The full manual is the [User Guide](USER_GUIDE.md).

## 2026-10-04

- **Gantt warning marks.** A new Gantt setting, **Warning column** (⋮ > Gantt style > Layout): every task with a value in that column gets an amber **!** just after its bar (after its label, when bars carry one); hovering the **!** shows the value. A task hidden in a folded summary task or swimlane puts its mark on the folded row, which lists the tasks inside. The bars do not change: the mark only tells. A new Gantt picks a column named Warning, Alert, Issue or Planner differs by itself; the AI context names the column (`chart_pm` `warning`). Made for project apps whose plan and task list can disagree ("Planner differs").

## 2026-10-03

- **Height free chart.** A new button in the Present bar (up-and-down arrows, shown when the deck has a Gantt; off by default, saved with the session as `presentTall`, so a deck saved with it on opens with it on): each Gantt takes the height its rows need - about 26 px a row, so fitted task names reach 14 px - even taller than the screen; the deck scrolls. Off again, the chart fits one screen as before. For plans with several projects, where one screen squeezes the names too small to read.
- **Gantt arrows reach folded rows.** A link whose task sits under a folded summary task or in a folded swimlane is now drawn to the row that hides it (the folded summary, or the lane header), at the task's own dates, as Planner draws it; before, it disappeared. A link inside one fold is not drawn; several links between the same two rows are drawn once, from the predecessor that ends last. The count of conflicting links now covers every link, folded or not.
- **Copy prompt on AI responses that came with a deck.** A deck's site may send back the full prompt its AI got (`{reply, prompt}` when Clues asks with `withPrompt`, or `aiOnOpenPrompt` next to a kept `aiOnOpen` reply); the entry in **Dataset > AI responses** keeps it, and **Copy prompt** puts it on the clipboard - to see exactly what the AI was told.
- **AI context: a presentation note keeps its look.** `chart_preso_note` now says plainly that an omitted attribute keeps that note's current value: to change only the words, pass `ref` and `text`.
- **A deck can ask for its AI reply as it opens.** A deck opened from a link may carry `aiOnOpenRequest` (an address on the deck's own site and an instruction). Clues then does what a user does with Copy AI context, without the copying: it builds its full AI context exactly as Copy AI context does by default (styling mode - every styling operation, slide comments included - all charts, data samples), sends it with the instruction to that address, and applies the answer like a pasted reply - validated, listed in **Dataset > AI responses**, undoable. A notice counts the wait. Only the site the deck came from is asked; any other address is refused and nothing is sent. `aiOnOpen` also takes the reply text as an assistant wrote it. The smoke test opens a deck that asks.
- **A deck can carry an AI reply to apply when it opens.** A `.clue` with an `aiOnOpen` field (an AI reply in the usual spec format) has it applied through the normal **AI import** as the deck opens - validated, applied, and listed in **Dataset > AI responses** with its undo - quietly, without the import dialog. A project app uses it to send its AI narrative (presentation notes, notes in charts, subtitles written from its latest data) with each deck, so the narrative can be seen and undone in Clues. Saving never writes the field back: it applies once per open. The smoke test opens such a deck.

## 2026-10-02

- **Gantt summary tasks, as in Planner and MS Project.** Pick the column that names each task's summary (parent) task - by task name or ID - under **⋮ > Gantt style > Summary tasks > Summary task column** (an auto-built Gantt picks a column called *Summary task* or *Parent* by itself). Each summary row then follows with its own tasks, gets a **bold** label and a thin **bracket bar** with end caps spanning its tasks (its own dates count only when none of its tasks is dated), and stays out of the status colors and the critical-path outline. **Click a summary bar to fold** its tasks away (the label turns from ▾ to ▸; links to the hidden tasks go with them) and click again to show them; folds are saved with the chart, so a deck can open folded. **Summary bar color** sits in the same section (default: the text color). Swimlanes are off while a summary column is set.
- **Security fix: rich text from a deck is always cleaned.** Presentation notes, the title slide and chart titles are now cleaned where they are shown, not only when edited, and the cleaner reads them in an inert document (before, markup such as an image with an error handler could already run while being cleaned). A .clue file is data from anywhere - with deck links (`#open=`), a crafted link could otherwise have run script on clues.ai. The smoke test opens such a hostile deck and fails if anything in it runs.
- **Gantt names: colored and fitted.** Once you set a **Swimlane bar color** or **Summary bar color**, the lane and summary names on the axis take the same color as their brackets (task names keep the axis color). New **⋮ > Gantt style > Layout > Fit task names to the rows (6-14 px)**: the names on the axis are sized to the row height after every draw, resize or fold - small for a crowded plan, back up to 14 px when projects are folded. The AI sets it as `fit_labels`.
- **Gantt task borders.** **⋮ > Gantt style > Bars > Border thickness** and **Border color** outline every task bar and milestone (the color defaults to the bar's own group color); the AI sets them as `border_width` / `border_color`. Outlines - the borders and the critical-path outline - now sit on top of the progress shading, which used to cover part of them.
- **"Pulling data from your feed..."** While a deck link (`#open=`) is being fetched, the start box says so and names the address it pulls from, instead of inviting a file drop; if the link fails, the usual box comes back with the reason.
- **Fold from the names too, with a pointing hand.** A swimlane or summary task now folds (and unfolds) by a click on its name on the axis as well as on its bracket bar, and the cursor turns into a pointing hand over both - the crosshair stays on everything else.
- **Swimlane bar color.** Swimlane brackets (for example one per project) can take a color of their own, apart from the summary tasks inside them: **⋮ > Gantt style > Layout > Swimlane bar color** (until set, lanes use the Summary bar color). The AI sets it as `lane_color`.
- **Gantt arrows drawn like Planner's.** Dependency arrows have rounded elbows, and when a task starts the moment its predecessor ends (or before), the arrow loops out to the right and comes back into the task from the left instead of running unseen along the bar edges. Arrowheads always point into the task; conflicting links stay dashed red, critical ones keep the critical-path color.
- **A lighter page for deck links: `https://clues.ai/live.html`.** The same app without the built-in Penguins showcase - about 0.42 MB to download instead of 0.9 MB - for decks opened from a link (`live.html#open=<address of a .clue>`). Opened without a link it lands on the start screen; your own session is restored as on the main page. `deploy-public.mjs` writes it on every deploy, and the smoke test checks it (no showcase, deck link presenting).
- **Swimlanes and summary tasks together; lanes fold.** **Swimlanes by** (for example Project) and the **Summary task column** now work together: each lane holds its own summary tree. Lane headers get the same bracket bar as summary tasks, and a **click on a lane folds the whole lane** to that one bar - with several projects, fold them all for a portfolio view and open one to see its tasks. Folding only hides rows; choosing which projects to show stays in the Filters. **Folded swimlanes** (Gantt style > Layout) counts the folded lanes and has **Unfold all**; the AI reads and sets them as `folded_lanes`. An auto-built Gantt on a table with several projects (a column called *Project*) starts with one lane per project.
- **The AI knows the summary settings.** The AI context explains them, and the chart_pm op reads and sets all three: `summary` (the column), `summary_color`, and `folded` (the summary task names whose tasks are hidden, e.g. `"folded": ["Question 2"]`; `[]` shows all). A chart's line in the context shows its summary column, bar color and folded summaries by name. The menu's **Folded summary tasks** row counts the folds and has **Unfold all**.

## 2026-10-01

- **Open a deck from a link.** `https://clues.ai/#open=<address of a .clue>` (or `?open=`) fetches the deck and opens it exactly like a dropped `.clue` - password prompt, drift check, and the saved Present mode - so a team can put "open the status deck" behind one click, with no file to download or pass around. If the deck has a connected data source, it checks it right away, so the charts show the source's latest data. The session you had is kept one step back: the "Deck opened" message offers **Back to my session**. Only https addresses are accepted (plus localhost for development); the site holding the deck must allow clues.ai to read it, and a refused or unreachable link says so and brings your session back. Use the `#open=` form when the address carries an access key: browsers never send the part after `#` to clues.ai. A phone-sized screen plays the linked deck as a presentation, like the welcome screen's Open button.
- **Smoke test** covers the link: the sample deck opened from `#open=` must present with data, and an address Clues does not accept must open nothing and say so.

## 2026-09-30

- **Project-management charts.** Four new types plus burnup/burndown, all native Plotly (no new dependency), each with AI encodings in the chart registry:
  - **Gantt (Over Time)** - tasks as bars from start to end (or a number of days), zero-length tasks as milestone diamonds, color by status/phase/owner, optional progress shading, a dashed Today line, start-date or data order. **As of** turns a history table (one row per task per snapshot) into the plan as of its latest snapshot. Suggested automatically on the Overview when the data looks like a plan. The Over Time tab now opens for a date plus a category, since plans often carry no numbers.
  - **Radar / spider web (Comparisons)** - one shape per group across 3+ measures picked with a compact **Spokes** checklist; mean or median; spokes in different units are rescaled 0-100% of their range and the chart says so (Auto / 0-100% / Raw values).
  - **Pareto (Comparisons)** - categories sorted high to low by row count or a measure's sum, cumulative % on a right axis, dashed 80% guide; the tail past 20 folds into "Other".
  - **Risk matrix (Comparisons)** - likelihood x impact with a count per cell and green/amber/red diagonal zones; levels order themselves (numbers, and common rating words); optional risk names in the hover.
  - **Burnup / burndown (time series "Values" menu)** - sum or count per date, running total with a dashed scope line (undated rows count toward scope), or remaining; optional **Finish by** date for an ideal line.
- **Gantt dependencies and critical path.** A **Depends on** column (predecessor names, or row IDs; MS Project codes like `5FS+2d` read as finish-to-start) draws arrows from each predecessor's end to its successor's start and outlines the critical path in red - the tasks with no slack, computed on the plan's own dates with a backward pass from the finish (nothing is rescheduled). Hover shows each task's slack; a successor that starts before its predecessor ends is a dashed red arrow with negative slack; the caption counts unmatched names and names any dependency loop. Toolbar toggles hide the arrows or the critical path.
- **Cumulative flow (Over Time).** Items (or a measure's sum) per status per snapshot date, stacked finished-at-the-bottom to backlog-on-top, from a history table with one row per item per snapshot. Suggested on the Overview when the data looks like one.
- **Burndown from snapshots.** "Sum per date" now takes a **Finish by** date too (ideal line from the first value to zero), and every per-date mode starts its axis at zero.
- **BI-style tuning for the project charts.** A new **Gantt style / Radar style / Burnup / burndown style** section in each chart's ⋮ menu: critical-path color and thickness, arrow color/thickness/arrowhead, bar height and bar labels, milestone shape/size/color, finished-part color, row shading, and a date line at today, the As-of date, or a chosen status date (color, style, thickness); radar spider-web grid (now the default), manual scale and rings, fill opacity, line thickness, markers, value labels, and a target ring; burn line shape, end label, and scope/ideal line styles. One table (`PM_STYLE_PARAMS`) drives the controls and a new AI styling op, `chart_pm`, validated knob by knob.
- **Gantt swimlanes, time axis, weekends, baseline.** Group rows by a column with lane headers and summary bars; days/weeks/week-number/month/quarter axes; weekend shading; baseline bars from planned start/end columns (auto-picked by name) with the finish variance in the hover.
- **Projected finish** on burnup/burndown: a toolbar toggle drawing a dashed straight line at the last N periods' pace to the scope or zero, captioned with the landing date and its distance from Finish by.
- **Annotate Chart** on the Gantt, the cumulative flow, and the Pareto.
- **Samples.** `project-plan-sample.csv` gained a Depends on column (and dates that give it a clean critical path plus one deliberate conflict); new `project-history-sample.csv` is the same project as nine weekly snapshots, with scope added mid-project. The plan sample also carries Baseline start/end columns (the slipped tasks' original dates).

## 2026-07-24

- **PowerPoint export: the deck background moved to the slide master.** Each slide used to paint its own background - and a gradient deck was silently flattened to its average color. The background now lives once on the slide master (solid colors as a native fill, gradients rendered to a background image honoring the deck angle), so editing the exported .pptx means changing ONE master in PowerPoint's View -> Slide Master, and gradients finally survive the trip.
- **Open-ended shades.** `chart_shade` accepts just one bound: only `to: 15` shades everything below 15, only `from: 250` everything above - the band runs to the edge of the axis and the label anchors at the finite edge. AIs kept writing this natural form ("Lightweight Class <2500 lbs") and getting rejected; now it means what it says. The AI context also states explicitly that annotation text sizes are per op (notes default 12px, shade/marker labels 10px - a house style must pass "size" on each).
- **Inside legends are draggable.** A legend placed "inside" the chart (by you or your AI) can now be grabbed and moved; the first drag converts it to a custom position that saves with the session. Dragging was previously reserved for legends already set to "custom" - and a guard silently discarded drags on anything else.
- **No dataset, no side panel.** Before any data is loaded the left panel had nothing to offer ("Upload data to see settings") - it now stays out of the way entirely and appears once a dataset or session is open. The **Dataset description** and **audit trail** header buttons disable too - nothing to describe or sign yet. The upload zone and the header's Load button already cover every way in.
- **"Appearance" is now "Style".** The middle sidebar tab reads **Filters | Style | Fields** - shorter, and everything in it is styling anyway (themes, series styling, backgrounds, layout). Every pointer in the guide and tooltips follows; saved sessions are untouched (the internal key never changed).
- **One Aliases section.** "Metric Aliases" and "Category & Date Aliases" merged into a single **Aliases** collapsible in Appearance - every column in one list (dates tagged), one Reset for all. The split was plumbing, not something worth two panels.
- **One continuous scroll through all your charts.** Browsing a chart family with the side panel open, an extra wheel push past the bottom of the page turns to the next family - and past the top, to the previous one. The push must be deliberate (a real nudge at the boundary, with a beat of lockout after each turn), so normal scrolling never switches tabs by accident.
- **The source-file pill moved home.** The dataset's file name now sits in the sidebar's Dataset group header, next to its chevron, instead of under the wordmark - one less line in the top bar.
- **A slimmer top toolbar.** The header lost a third of its height: the wordmark is smaller, the copyright line is gone, and the buttons carry one-word captions that never wrap - AI context, AI import, Excel, Save, Share, Load, New Dataset, Clear. The tooltips still spell out exactly what each one does.
- **Sankey arrangements survive.** Drag the nodes into the layout you want - the positions now save with the chart (keyed by node name), persist through autosave, session files, and sharing, and restore exactly on reload. Nodes without a stored spot (new data values) simply flow into place. Also: parallel ribbons of the same pair now alternate shade depth and every ribbon carries a hairline seam, so per-row splits are visible at rest, not only under the mouse.
- **Sankey, the SankeyMATIC cut.** Three refinements to the edge-list flow diagram: node captions now put the amount on its **own line under the name** (the income-statement look); **duplicate source->target rows stay separate parallel ribbons** instead of being summed - hand-authored splits (which slice of Net Sales becomes Cost vs Gross Margin) keep their meaning (very large link files still aggregate for speed); and hovering a band no longer **doubles the amounts** - the tooltip reads bare names plus the band's own value. Nodes were already draggable; their two-line captions ride along.
- **CRITICAL: sessions with year-style date columns opened with every chart blank.** The 2026-07-25 change that turns numeric calendar values into real dates (2007 -> 2007-01-01) silently invalidated the DATE FILTERS of every session saved before it: the saved filter still listed "2007", no row matched, and every chart - the Palmer Penguins showcase included - rendered empty axes. Restoring a session now migrates its date-filter values through the same rules, so legacy sessions, portables, and the showcase all heal on open. The smoke test now also asserts that showcase charts actually carry data - counting chart frames alone is how this one slipped through.
- **Tile region maps: the blank-chart bug, actually fixed.** A tile choropleth draws nothing until its boundary file arrives from the CDN - but the chart's trace cache didn't know when it had, so the empty chart stuck for good unless some unrelated setting forced a recompute (which is why toggling "Chart toolbars" seemed to cure it). The boundary load now invalidates the cache: the map appears on its own the moment the boundaries land, in every view, toolbars or not - and the replay starts right up.
- **Tile-map replay: no more dead white maps.** On Streets/Light/Dark basemaps, a replay step fired while mapbox-gl was still loading its style crashed inside Plotly (an async error no guard could catch) and could blank the map for good - with real network latency this hit most presentation opens, and only a resize (e.g. expanding the chart controls) revived it. Replay steps now wait for the map style to be ready, at boot and after any rebuild. The on-map play chip also got smaller and quieter.
- **Race bars: newcomers get their bar.** The bars panel's category axis froze on the opening cast, so a series entering mid-race (data starting at a later date) landed outside the axis and stayed invisible until a manual autoscale. The panel is now sized for the full cast from frame one - series without data yet wait at the bottom of the axis with no bar, and rise into rank the moment their first value arrives.
- **Maps: play and pause ON the map.** The replay's only play button lived in the toolbar - hidden exactly when presenting, so a deck saved paused could never start. A small ▶/⏸ chip now sits at the map's bottom-left corner beside the scrubber, in every view: start, pause, and scrub a replay without any toolbar. The state still saves with the session.
- **One Play/Pause button on the bar race - and Pause means stop.** The separate Play and pause buttons confused: now a single button toggles (it flips between "Play" and "Pause"), and pausing **empties the queue** - the interrupted run doesn't count as a playthrough and any pending repeat is cancelled, so the race never resumes on its own. Grabbing the timeline does the same. Play after a pause resumes from that spot with a fresh repeat count; Play at the end rewinds and starts over.
- **Every racing bar gets its name.** With many series Plotly silently dropped every other bar label - an unlabeled bar says nothing. The bars panel now labels every bar, shrinking the font to fit the chart's height (floor 7px).
- **Maps: replay saved ON now starts by itself in Present.** A session saved with the replay running (say, infinite loops) could open into Present with a still map: the replay engine checked for the plot before Plotly had finished building it and gave up for good. It now waits for the plot and then starts - fresh loads, Present slides building as they scroll into view, all covered.
- **Race caption dodge, the OWID way.** The first cut of caption de-collision spread labels across the whole axis (guessing at the chart's height), sometimes parking the leader off-plot. Now: captions stay exactly at their value unless they truly collide; a colliding group spreads only as far as needed, centered on its own values and clamped inside the plot; each displaced caption gets a thin **leader line** back to its line end - the device Our World in Data uses; and when the captions physically cannot fit the chart's real height, the font auto-shrinks (floor 8px) before any overlap is allowed. Also fixed: replaying the race (Plays x2+) now properly rewinds the trails - the restart and the play no longer race each other.
- **Bar race gets the map replay's controls.** The race toolbar now carries **Plays** (x1 / x2 / x3 / x5 / infinity - Plotly plays frames once, so the card restarts the run itself), a **0.5x** speed below Slow, and a **spacer** between the trail and the bars panel (a % of the width, empty = 8) for decks where the trail's name captions were crashing into the bar labels.
- **Race captions: sized, wrapped, and de-collided.** Two new boxes set the line-end captions' **size** (px) and an optional **wrap width** (characters), so long names stack onto short lines instead of running into the bars. Captions that would overlap - lines ending at nearly the same value - are now **spread apart vertically** and kept inside the plot, no longer printing on top of each other.
- **Race numbers follow the field's format.** The values at the end of the bars, and the ones in the trail captions, honor the **Decimals / thousands / prefix / suffix** set in the Fields tab (they were hardcoded to 4 significant decimals), and the timeline's step readout follows the date field's **display format** ("1952", not "1952-01-01") - the same rule the map replay ticker uses.
- **Long axis labels stop being sliced off.** Category names on a horizontal bar chart ("Central and South America (IEA)") were cut at the figure's left edge, and no axis control could rescue them - the fixed margin, not the axis position, was the cage. Every axis now grows its margin to fit its tick labels; nothing that already fit moves.
- **Bar legends read the category names.** Switching the legend on for a plain bar chart used to produce a single entry labelled "trace 0" - Plotly's name for an unnamed trace. Each bar is now its own named series, so the legend lists the actual categories in their colors and each entry hides or shows its bar. (Value-scaled fills and single-series charts name the entry after the measure instead.)
- **Map replay ticker follows the contrast rules.** The big caption showing the current replay value used to default to near-white - invisible on the plain white Outline basemap. It now defaults to the same contrast ink as everything else (dark text on light basemaps and canvases, light on dark tiles or a dark deck), and the toolbar color chip shows the effective color; picking a color still overrides.
- **The Fields list scrolls in place.** With a wide dataset (19+ columns) the field cards ran the sidebar into a very long trek; the list now lives in its own bounded scroll region (like Series Styling), so every column is a wheel-scroll away without leaving the panel header behind.
- **Bubbles on categorical and date axes.** A scatter's X or Y can now be a category or a date field, not just a measure - sized dots per category over the years is the Our-World-in-Data natural-disasters look (Y = disaster type, X = year, size = deaths). Hover shows category values as themselves, and the numeric-only extras (trendline, marginal distributions, jitter) quietly sit out on a non-numeric axis. The AI's scatter/bubble types accept the wider axes too.
- **Bubble charts, one click away.** The chart's own type dropdown carries the identity too: a sized scatter shows as Bubble, picking Bubble adds a size field, picking Scatter clears it - no more silent revert. A Bubble entry joins the Relationships picker (a scatter preconfigured with a third measure on point size), the analyzer suggests a "Bubble view" when three or more measures exist (axes = the most correlated pair, size = the most varied remaining measure), and the AI catalog gains a bubble type (x, y, size, color) so "build a bubble chart" lands correctly. Suggested charts also stopped treating a sized scatter as a duplicate of the plain one.
- **The analyzer spots date-shaped numbers too.** A numeric column named like a year (holding 1500..2200 integers) or shaped YYYYMM / YYYYMMDD now gets its own "Treat as dates?" suggestion with a one-click Convert - on Palmer Penguins, converting year immediately surfaces a "Trend over time" suggestion, unlocking the whole Over Time family (time series, forecasts, decomposition, replays) plus date filtering. Bare years become real dates (2007 reads as 2007-01-01), and such columns no longer compete in the treat-as-categories advice - the date reading wins.
- **Waterfall charts.** A new Comparisons type - the P&L bridge: each category is a relative step (the sum of the metric; positives rise green, negatives fall red), connectors between bars, signed value labels, and an automatic Total bar you can toggle off. Steps follow the data's own order, colors and orientation sit in the toolbar, hover shows each step's change and running total, and in-chart annotations work on it. AI: the waterfall type (steps + change encodings) and chart_display wf_up_color / wf_down_color / wf_total_color / wf_total. Native Plotly - no new dependency.
- **Charts open at one-slide height in Presentation view.** A chart with no explicit height now fills the window's vertical space - each chart IS one slide from the get-go, sized to whatever screen shows the deck (the default is computed live, not stored, so a shared deck refits any monitor). Dragging a height still pins that chart to your chosen size.
- **One click turns discrete numbers into categories.** The Stat overview's "Treat discrete numbers as categories?" advice now carries a Convert button that retypes every candidate column at once - and the analyzer immediately re-runs on the new types, surfacing grouping suggestions (compare distributions/averages across groups) that were impossible while those columns were numeric. The Fields tab can still flip any column back.
- **Series start at 15% transparency.** New sessions default every series to 85% opacity instead of 70% - crisper points and bars out of the box. Saved house styles, saved sessions, and any slot you have styled keep their own values.
- **A pencil button for presentation edit mode.** The toolbar gains an icon-only pencil just left of Present: one click hides the side panel and drops you into presentation editing (notes, images, sizes, placements) - the same switch the logo toggle performs, now discoverable; click again to return to the workspace.
- **PowerPoint charts embed as SVG.** Vector charts land on the slides as real SVG (with an automatic PNG fallback for old Office clients) - in PowerPoint, right-click a chart and Convert to Shape to edit every line, label, and point natively. WebGL charts (3D, scatter matrix, tile maps) cannot vectorize and stay high-resolution PNG.
- **The title slide exports true to the deck too.** Slide 1 of the PowerPoint and PDF exports now replays the rendered title slide - the heading, the date, the rich description text (as an editable text box in PowerPoint), and the slide image, each at its measured position and proportional size, including dragged layouts. The centered synthetic page remains only when the description slide is off. A font-scale slip in the measured note text (33% oversized in PowerPoint) is fixed in the same pass.
- **Slide exports now REPLAY the rendered deck.** Instead of re-deriving the layout from settings, the PowerPoint and PDF exports measure each slide as it renders on screen - the plot, the presentation note, and the deck image land on the page at the exact positions and sizes they occupy in the deck, including dragged free notes, gutter images, and 12-column grids. Note text scales to keep its on-screen proportion. (The settings-based layout remains as a fallback for unmounted charts.)
- **Exports save where you point them again.** The folder picker demands a live click, but slide composition takes long enough to lose it - the console showed SecurityError and a silent fallback. The destination is now acquired the moment you click the export, and the file is written there when the bytes are ready.
- **Slide exports honor the deck image geometry.** The PowerPoint and PDF exports were sizing every chart-side image at a fixed width and ignoring free placement; they now carry the authored width (band px or %), the side placements at their edges, and free-placed images at their own x/y - overlaid without shrinking the chart, and measured against the real presentation band.
- **The 3D-trajectory suggestion stops firing on category-like numbers.** "Change smoothly from row to row" used to trigger on small repeating integers (1, 4, 4 ... 1, 5, 4) whose sorted order merely looked monotonic. A path coordinate now needs many distinct values, few flat repeats, and a much higher smoothness bar - real x/y/z data (mesh files, tracks) still suggests, grouping codes never do.
- **The PDF export is now composed, not printed.** The Export menu's PDF is built page by page like the PowerPoint export - one landscape page per slide (chart + note + image + deck background), a contents page with clickable internal links, charts embedded as fast-writing JPEGs - and saves directly with no print dialog. Browser printing shears slides inside flex/grid layouts on some decks; composing sidesteps the print engine entirely. Ctrl+P remains for whoever wants the browser's version.
- **Export to PowerPoint.** The Present bar's new Export menu saves real 16:9 .pptx slides: title slide, CLICKABLE contents slide, a divider per section, then one slide per chart - the chart as a high-resolution image, the presentation note as an EDITABLE text box (bold, italics, colors, bullets, sizes carried over), the deck image embedded, and the deck background as the slide background. Faceted charts tile their panels. Built fully in the browser (pptxgenjs, pinned, loaded on first use).
- **PDF pages no longer shear slides.** Chromium cannot page-break inside flex or grid containers - the chart list is laid out as plain blocks while printing, so every page now holds exactly one whole slide (the 8-slide showcase prints 13 pages: title, contents, dividers, slides - was 28 broken fragments).
- **Print the whole presentation to PDF, one slide per page.** A print button in the Present bar (beside the arrows) prints the deck the way it presents: each slide - the chart WITH its presentation note and deck image - gets its own page, a clickable CONTENTS page opens the document (the links survive in the saved PDF), the deck background prints, and WebGL charts (3D, scatter matrix, tile maps) are snapshotted first so they never print blank. Page orientation is measured from the slides (landscape for the usual wide deck, portrait for tall ones) - in the dialog just choose Save as PDF and turn Background graphics ON.
